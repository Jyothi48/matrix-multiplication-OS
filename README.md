# Threaded Matrix Multiplication

This project demonstrates matrix multiplication using **Python threads** with **TensorFlow** and **NumPy**.

## Features

- Multiplies two 100 × 100 matrices
- Uses multiple threads for matrix multiplication
- Uses TensorFlow for matrix creation and result verification
- Displays sample thread operations in the terminal
- Includes an animation to demonstrate the matrix multiplication process

## Technologies Used

- Python
- TensorFlow
- NumPy
- Matplotlib
- Python Threading
